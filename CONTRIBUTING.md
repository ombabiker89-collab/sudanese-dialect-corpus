# Contributing to Sudanese Dialect Corpus

Thanks for helping preserve and improve Sudanese Arabic in AI!

## Guidelines
- Use authentic Sudanese spelling (e.g. شنو not ماذا)
- Tag region if possible (Khartoum, Darfur, etc.)
- Keep conversations natural
- Avoid mixing with Egyptian or Levantine unless intentional

## Steps
1. Add to data/ or vocab/
2. Commit with clear message
3. Open PR
